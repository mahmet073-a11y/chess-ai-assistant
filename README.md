# Chess AI Assistant v0.2 - Android training prototype

This update is meant to be copied over the existing repository's root. It preserves the existing working `build.gradle.kts`, `settings.gradle.kts`, and GitHub Actions workflow, replacing only the Android app sources, manifest, and the app Gradle file.

Features: manual training chess board, elementary locally implemented move suggestion, movable overlay window, manual overlay permission prompt.

Limitations: not Stockfish; castling and en passant not implemented; not tested on a physical device.
